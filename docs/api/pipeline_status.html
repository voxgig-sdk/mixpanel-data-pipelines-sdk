GET /nessie/pipeline/status

Operation ID: get-warehouse-pipeline-status.

Authentication: basic token (ServiceAccount) or basic token (ProjectSecret).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | project_id | query | integer | Yes | Required if using service account to authenticate request. | | name | query | string | Yes | The name that uniquely identifies the pipeline. | | summary | query | string | No | Default: false. Only lists task count by status and no details. | | status | query | array of string | No | Filters the tasks by the given status. Valid options for status are pending, running, retried, failed, canceled, and timed_out. |
